# هایپر باتری ماهر — نسخه تحویل نهایی

این پروژه یک سایت معرفی/تبلیغاتی چندصفحه‌ای برای فروشگاه هایپر باتری ماهر است.
**سبد خرید، پرداخت و فروش اینترنتی ندارد.**

## صفحات
- خانه
- برندهای موجود
- خدمات
- راهنمای انتخاب باتری
- سوالات متداول
- درباره ما و گالری
- تماس و مسیریابی
- پنل مدیریت

## پنل مدیریت چه کارهایی می‌کند؟
مدیر می‌تواند:
- محصول جدید اضافه کند
- برند، نام، دسته‌بندی، آمپراژ، قیمت و توضیحات را تغییر دهد
- تصویر محصول را مستقیماً آپلود کند
- محصول را فعال/مخفی کند
- محصول را ویرایش یا حذف کند
- برند جدید اضافه/ویرایش/حذف کند
- شماره تماس، آدرس و لینک‌های Google Maps، نشان، بلد، Instagram و WhatsApp را تغییر دهد

## راه‌اندازی Supabase
1. در Supabase یک پروژه بساز.
2. فایل `supabase/schema.sql` را کامل در SQL Editor اجرا کن.
3. در Authentication یک کاربر مدیر بساز.
4. بعد از ساخت کاربر مدیر، شناسه UUID آن کاربر را در جدول `admin_users` قرار بده:
   `insert into public.admin_users(id) values ('UUID-کاربر-مدیر');`
5. مقدار Project URL و anon/public key را در `js/config.js` قرار بده.
6. سایت را روی GitHub Pages منتشر کن.

**Service Role Key را داخل سایت، JavaScript یا GitHub قرار نده.**

## انتشار روی GitHub
محتویات این پوشه را در repository قرار بده و GitHub Pages را روی branch اصلی و پوشه root فعال کن.

## نکته مهم برای صاحب مغازه
شماره تلفن عمداً در پروژه حدس زده نشده است. صاحب مغازه آن را از پنل مدیریت وارد می‌کند تا شماره اشتباه روی سایت نمایش داده نشود.


## ساختار نهایی
صفحات عمومی سایت داخل پوشه `pages/` هستند؛ فایل‌های JavaScript داخل `js/` قرار دارند. این ساختار برای Live Server و GitHub Pages آماده شده است.
